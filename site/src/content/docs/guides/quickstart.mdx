Get started using Modus Bootstrap in seconds by including our production-ready CSS and JavaScript by [using a CDN]([[docsref:/getting-started/install#cdn]]) without the need for any build steps. CDNs provide copies of Modus Bootstrap’s codebase that’s ready to be used in any environment with minimal code changes required on your part.

## Live demo

**Already familiar with setting up HTML pages?** See the end result in this [Bootstrap CodePen demo](https://codepen.io/team/bootstrap/pen/qBamdLj).

## Steps

1. **Create a new `index.html` file in your project root.** Include the `<meta name="viewport">` tag as well for [proper responsive behavior](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/meta/name/viewport) in mobile devices.

   ```html
   <!doctype html>
   <html lang="en">
     <head>
       <meta charset="utf-8">
       <meta name="viewport" content="width=device-width">
       <title>Modus Bootstrap demo</title>
     </head>
     <body>
       <h1>Hello, world!</h1>
     </body>
   </html>
   ```

2. **Include Modus Bootstrap’s CSS and Bootstrap’s JS.** Place the `<link>` tag in the `<head>` for our CSS, and the `<script>` tag for our JavaScript bundle (including Floating UI for positioning menus, popovers, and tooltips, and Vanilla Calendar Pro for the datepicker) before the closing `</body>`. Learn more about [our CDN links]([[docsref:/getting-started/install#cdn]]).

   ```html
   <!doctype html>
   <html lang="en">
     <head>
       <meta charset="utf-8">
       <meta name="viewport" content="width=device-width">
       <title>Modus Bootstrap demo</title>
      <link href="[[config:cdn.css]]" rel="stylesheet"><!--[!code highlight]-->
     </head>
     <body>
       <h1>Hello, world!</h1>
       <script type="module" src="[[config:cdn.js_bundle]]" integrity="[[config:cdn.js_bundle_hash]]" crossorigin="anonymous"></script><!--[!code highlight]-->
     </body>
   </html>
   ```

   Choose the JavaScript file that fits your setup:

   - `bootstrap.bundle.js` includes [Floating UI](https://floating-ui.com/) and [Vanilla Calendar Pro](https://vanilla-calendar.pro/). You can load it directly with `<script type="module">`.
   - `bootstrap.js` references both dependencies. When you load it directly in a browser, you must provide both dependencies through an import map.

   Use this import map with the non-bundle file:

   ```html
   <script type="importmap">
   {
     "imports": {
       "@floating-ui/dom": "[[config:cdn.floating_ui_esm]]",
       "vanilla-calendar-pro": "[[config:cdn.vanilla_calendar_pro_esm]]"
     }
   }
   </script>
   <script type="module" src="[[config:cdn.js]]" integrity="[[config:cdn.js_hash]]" crossorigin="anonymous"></script>
   ```

   To omit either dependency, [import only the Modus Bootstrap components you use or use a bundler with tree shaking]([[docsref:/customize/optimize#lean-javascript]]).

3. **Hello, world!** Open the page in your browser of choice to see your Bootstrapped page. Now you can start building with Modus Bootstrap by creating your own [layout]([[docsref:/layout/grid]]), adding dozens of [components]([[docsref:/components/buttons]]), and utilizing [our official examples]([[docsref:/examples]]).

## Optional font

Modus Bootstrap's source code defaults to a [native font stack]([[docsref:/content/reboot#native-font-stack]]), but we use a custom font for our hosted documentation to for more consistent styling across platforms. We use [Open Sans](https://fonts.google.com/specimen/Open+Sans), and recommend using the same or similar in your project.

1. **Add the Open Sans web font from Google Fonts.** Add the following to your `<head>`, before Modus Bootstrap’s CSS:

   ```html
   <!doctype html>
   <html lang="en">
     <head>
       <meta charset="utf-8">
       <meta name="viewport" content="width=device-width">
       <title>Modus Bootstrap demo</title>
       <link rel="preconnect" href="https://fonts.googleapis.com"><!--[!code highlight]-->
       <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin><!--[!code highlight]-->
       <link href="https://fonts.googleapis.com/css2?family=Open+Sans:ital,wght@0,300..800;1,300..800&display=swap" rel="stylesheet"><!--[!code highlight]-->
       <link href="[[config:cdn.css]]" rel="stylesheet">
     </head>
     <body>
       <h1>Hello, world!</h1>
       <script type="module" src="[[config:cdn.js_bundle]]"></script>
     </body>
   </html>
   ```

2. **Apply the font by overriding Modus Bootstrap’s CSS variable.** You can do this in a `<style>` tag in your `<head>` or in a custom CSS file.

   ```html
   <style>
     :root {
       --bs-body-font-family: "Open Sans", system-ui, sans-serif;
     }
   </style>
   ```

   You can also do the same in your custom Sass file should you graduate from a CDN setup to one that includes Modus Bootstrap via a package manager.

Learn more about Modus Bootstrap’s typography defaults in [Typography]([[docsref:/content/typography]]) and [Reboot]([[docsref:/content/reboot#native-font-stack]]).
